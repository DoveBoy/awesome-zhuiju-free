# 关于 Awesome Zhuiju Free（追剧么指南）：我为什么做这个追剧资源导航

以前为了找一部想看的剧，我经常在深夜翻遍搜索结果。链接倒是不少，点进去却像开盲盒：有的套着好几层跳转，有的播放器里塞满小广告，还有的必须先看广告、装应用，折腾半天也没看到正片。

我受够了这种体验，于是做了开源项目 Awesome Zhuiju Free，并给它的网页版取名“追剧么指南”。这里专门整理免费、广告少、体验相对干净的追剧网站、应用和相关工具。它不是影视站，也不存放影片，只是一份有人筛选、有人维护的资源指南。

## 为什么会有这个项目

网上从来不缺影视资源，真正稀缺的是一份省心的清单。

很多导航只负责把链接堆在一起。站点还能不能打开、广告多不多、域名有没有更换，往往没人管。等到真正想看时，收藏夹里十个链接可能有八个已经失效。

Awesome Zhuiju Free（追剧么指南）想解决的就是这件小事：先帮你做一轮筛选，再通过自动任务每天检查链接状态。打开清单后，可以优先尝试标记为“可访问”的资源，少点几次失效链接，也少踩几个弹窗广告的坑。

项目目前整理的内容包括在线影视、影视 APP、网盘搜索、字幕资源、TVBox / 影视仓配置、IPTV 以及开源播放器项目。完整清单公开放在 GitHub，任何人都可以查看数据、反馈失效或参与维护。

## 这里的内容怎么用

所有整理结果都可以免费查看，没有注册门槛，也不会为了查看链接强制你看广告。

- 普通用户可以打开 [追剧么指南](https://zhuiju.me) 直接浏览。
- 想查看完整数据、提交问题或参与维护，可以访问 [GitHub 项目](https://github.com/laoma2053/awesome-zhuiju-free)。
- GitHub 访问不方便时，也可以查看 [Gitee 镜像](https://gitee.com/laoma2053/awesome-zhuiju-free)。

需要说明的是，页面上的可用性状态只代表自动检测时的网络结果。第三方站点可能临时维护、更换域名，也可能受地区和网络环境影响。如果一个入口打不开，换一个通常比反复刷新更省时间。

## 收录标准

我希望这份清单宁可少一点，也不要为了数量什么都放。资源通常会从内容质量、更新情况、广告体验、访问稳定性和风险几个方面检查。

下面这些情况，一般不会进入推荐清单：

- 画质太差，内容长期不更新；
- 弹窗、诱导下载或跳转广告过多；
- 存在钓鱼、恶意软件、诈骗、成人或其他明显违法内容；
- 核心内容完全收费，却把自己包装成免费资源；
- 名称、简介和实际功能对不上，或者刻意隐瞒登录、付费与安装要求。

免费和相对干净是基本要求，但我也不想把话说得太满。第三方网站随时可能改变运营方式，所以收录以后仍会继续检测；发现体验变差、链接失效或风险增加时，会调整说明、降低推荐或移出清单。
