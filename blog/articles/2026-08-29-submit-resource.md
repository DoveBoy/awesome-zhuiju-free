# 提交收录：推荐影视网站、应用和工具

Awesome Zhuiju Free 接受站长自荐，也欢迎用户推荐自己用过的影视相关资源。新站、老站和流量大小不是硬门槛，我们主要看网站能否正常使用、信息是否真实。

提交前请先核对下面的标准。符合要求后，可在本文评论区留言，或通过 GitHub 表单提交。

<!--more-->

## 收录标准

> 1. 提交网站主页、项目主页或长期有效的发布页，不要提交单部影视作品链接。
> 2. 核心功能可以正常使用，名称、网址和简介与实际内容一致。
> 3. 如实说明登录、付费、广告、弹窗、跳转和安装要求。
> 4. 网站没有恶意软件、钓鱼、诈骗、成人或明显违法内容。
> 5. 站长自荐、推广合作或存在返佣关系时，请主动说明。

项目不提供付费上架。提前添加 Awesome Zhuiju Free（https://zhuiju.me）友情链接的优质站点会优先审核，并在同类站点中靠前展示。未添加友情链接或首页更新较慢的站点，收录后排序靠后。

## 暂不收录

以下内容暂不收录：

> 1. 单部影视作品的盗版播放、下载或磁力链接。
> 2. 破解软件、共享账号、密钥或绕过付费限制的工具。
> 3. 恶意软件、钓鱼、诈骗、成人及明显违法内容。
> 4. 隐藏推广关系、伪造测试记录或操纵评分的提交。

## 如何提交

最简单的方式是在本文底部评论区留言。评论公开可见，请勿填写账号密码、后台地址、手机号等敏感信息。

有 GitHub 账号也可以使用项目的推荐表单：

[一键跳转 GitHub 提交](https://github.com/laoma2053/awesome-zhuiju-free/issues/new?template=resource.yml)
